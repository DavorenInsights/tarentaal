# Tarentaal Dash V6.1 Tutorial Arrow Patch

Apply this patch over Tarentaal Dash V6.

## Change
- Jump and duck arrows are shown only for the first 10 obstacle groups of each run.
- From obstacle group 11 onward, the prompt disappears and play relies on obstacle recognition and rhythm.
- The tutorial resets whenever a new run starts.

## Install
Extract this ZIP into the repository root and overwrite matching files.
