# Tarentaal Minigame Centre

A static HTML5 minigame collection designed for GitHub Pages.

## Current games

- **Tarentaal Dash V6** — polished South African endless runner
- **Tarentaal Tussle** — arena survival prototype
- **Tarentaal Fladder** — rhythm-flight prototype

Dash is currently the flagship game and has received the full production-quality pass.

## Deploy

Upload the contents of this folder to the root of a GitHub Pages repository. No build step or server-side code is required.

## Test

```bash
npm test
```

## Dash V6 highlights

- Four regional routes: Pretoria, Bloemfontein, Karoo and Lowveld
- High-quality compressed regional backgrounds
- Region-specific moving parallax layers
- Continuous animated dirt road in every route
- Dynamic player and obstacle shadows
- Krrr-Rush reward loop
- Fair validated obstacle scheduling
- Desktop and mobile controls
- Local high-score persistence
