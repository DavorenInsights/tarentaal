# Tarentaal Tussle V1

A dependency-free HTML5 top-down arena-survival game built for GitHub Pages.

## Controls

- Move: WASD, arrow keys, or the mobile joystick.
- Veersprong: Space or the mobile button.
- Pause: P, Escape, or the pause button.
- Upgrade cards: click/tap or keys 1–3.

The game saves the best score in browser localStorage. No build step or server is required.
