# Tarentaal Fladder V1

A self-contained HTML5 canvas game for the Tarentaal Minigame Centre.

## Controls
- Space, W, Up Arrow, click or tap: flap
- P or Escape: pause
- Mobile: on-screen flap button

## Features
- Five farm-themed obstacle styles
- Stamina-based flapping
- Mielie collectibles and near-miss bonuses
- Temporary Veerkrag shield
- Speed progression and day/night cycles
- Local best score and medals
- Sound, pause and fullscreen
