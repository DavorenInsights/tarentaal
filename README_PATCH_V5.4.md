# Tarentaal Cumulative Patch V5.4

This is a consolidated patch that supersedes the earlier standalone patches.

## Includes all changes so far
- Device optimisation selector on the minigame hub: Auto / Phone / Laptop
- Updated hub copy and styling
- Tarentaal Dash converted to a cleaner **endless runner** flow
- Barn obstacle replaces the old washing line obstacle
- Dash phone/laptop layout improvements
- Regional route system:
  - Pretoria
  - Bloemfontein
  - Karoo
  - Lowveld
- Higher-quality regional painted background assets
- Improved ducking tarentaal sprites
- Improved hadeda obstacle art
- Tarentaal Fladder phone/laptop optimisation support
- Tarentaal Fladder flapping-wing asset states

## Recommended base
You can apply this over:
- **Tarentaal Minigame Centre V2 Fladder**, or
- a newer repo state if you just want to overwrite with the latest changed files.

## Install
1. Open your current Tarentaal minigame repository folder.
2. Extract this ZIP into the **repository root**.
3. Allow matching files to be overwritten.
4. Commit and push to GitHub Pages.

## Notes
This cumulative patch is intended to replace the need to apply older patches separately.
